# Role-Specific Decision Framework

When multiple technically valid options exist:

1. Start from user outcome and constraints.
2. Identify the highest-risk assumption.
3. Prefer the simplest option that satisfies the requirement.
4. Consider security, reliability, maintainability, performance and cost.
5. Check interoperability with the rest of the system.
6. Prefer reversible decisions for uncertain areas.
7. Record important trade-offs.
