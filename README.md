# Next-Gen Claude Skills

A curated open-source collection of reusable Claude skills for software engineering, AI, research, product development, automation, and engineering leadership.

## Skills

| # | Skill | Focus |
|---|---|---|
| 01 | `next-gen-full-stack-engineer` | End-to-end full-stack product engineering |
| 02 | `ai-systems-architect` | AI systems and agent architecture |
| 03 | `ai-ml-engineer` | AI, ML, LLM and RAG engineering |
| 04 | `devops-cloud-sre-engineer` | Cloud, DevOps, deployment and reliability |
| 05 | `cybersecurity-engineer` | Security engineering and threat modeling |
| 06 | `database-data-engineer` | Data architecture and engineering |
| 07 | `software-system-architect` | Software architecture and system design |
| 08 | `product-engineer-zero-to-one` | Product development from idea to MVP |
| 09 | `ui-ux-design-engineer` | UI/UX and design systems |
| 10 | `mobile-app-engineer` | Mobile application engineering |
| 11 | `game-developer` | Game development |
| 12 | `qa-test-automation-engineer` | QA, testing and automation |
| 13 | `performance-engineer` | Performance engineering and optimization |
| 14 | `ai-automation-architect` | AI and workflow automation |
| 15 | `data-analyst-research-scientist` | Data analysis and research |
| 16 | `technical-writer-documentation-engineer` | Technical writing and documentation |
| 17 | `git-code-review-engineering-manager` | Git, code review and engineering quality |

## Using a skill

Each skill is self-contained. Open its directory and follow the instructions in `SKILL.md` when adding it to Claude or another compatible agent workflow.
